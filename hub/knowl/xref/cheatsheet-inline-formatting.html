Inline Formatting.

Emphasis
🔗
<em>emphasis</em>
Renders as: emphasis.
🔗
New term
🔗
<term>new term</term>
Renders as: new term (bold). Use when introducing vocabulary for the first time.
🔗
Inline code
🔗
<c>inline code</c>
Renders as: inline code. Use for filenames, commands, short code, and tag names in prose.
🔗
Alert
🔗
<alert>attention</alert>
Renders as: attention (bold italic). Use sparingly for genuine emphasis.
