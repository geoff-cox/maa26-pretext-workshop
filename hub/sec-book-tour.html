    Section 4:10-4:20 What Can PreTeXt Do?

    Before you write any PreTeXt yourself, it helps to see where this is going. The key idea is that you describe what your content is. It might be a definition, an example, an exercise, or an interactive. Then PreTeXt decides how it should look on the page, in a PDF, on a phone, or through a screen reader.
    🔗
    The gallery below shows some of what’s possible. You are not expected to build any of this today. Skim it, get a sense of the range, and come back to it later when you want ideas.
    🔗

    Subsection Interactive Feature Gallery

    Subsubsection GeoGebra

    GeoGebra is a powerful tool for creating interactive math visualizations. You can build an applet in GeoGebra and then embed it directly into a PreTeXt document with a single tag.
    🔗

    🔗

    Subsubsection Desmos

    Desmos is another popular tool for creating interactive math visualizations. Like GeoGebra, Desmos graphs embed directly into a PreTeXt document.

    Subsubsection ✔ True/False Questions

    Auto-graded true/false questions with targeted feedback. Students see an explanation tailored to the answer they gave.
    🔗
    Checkpoint 1. True/False.
      Every vector space has finite dimension.
      🔗

    • True.

    • The vector space of all polynomials with finite degree has a basis, \(B = \{1,x,x^2,x^3,\dots\}\text{,}\) which is infinite.

    • False.

    • The vector space of all polynomials with finite degree has a basis, \(B = \{1,x,x^2,x^3,\dots\}\text{,}\) which is infinite.
    🔗
    🔗

    Subsubsection ✔ Multiple-Choice Questions

    Multiple choice with per-option feedback, hints that reveal in sequence, and the option to randomize choices at build time.
    🔗
    Checkpoint 2. Multiple-Choice, Not Randomized, One Answer.
    What color is a stop sign?
    🔗
    • Green
    • Green means“go!”.
    • Red
    • Red is universally used for prohibited activities or serious warnings.
    • White
    • White might be hard to see.
    Hint 1.
    What did you see last time you went driving?
    🔗
    🔗
    Hint 2.
    Maybe go out for a drive?
    🔗
    🔗
    🔗
    🔗

    Subsubsection ✔ Matching Questions

    Drag-and-drop matching, useful for pre-reading checks or review.
    🔗
    Checkpoint 3. Exponential Integration Rules.
      Match each function of \(t\) with its antiderivative. Assume \(K\) is a constant.
      🔗
    • \begin{equation*} f(t) = \frac{K}{t} \end{equation*}
    • \begin{equation*} K\ln|t| + C \end{equation*}
    • \begin{equation*} g(t) = \frac{1}{K} \end{equation*}
    • \begin{equation*} \frac{t}{K} + C \end{equation*}
    • \begin{equation*} h(t) = e^{Kt} \end{equation*}
    • \begin{equation*} \frac{1}{K} e^{Kt} + C \end{equation*}
    • \begin{equation*} h(t) = e^{K} \end{equation*}
    • \begin{equation*} t e^{K} + C \end{equation*}
    • \begin{equation*} m(t) = \frac{t}{K} \end{equation*}
    • \begin{equation*} \frac{t^2}{2K} + C \end{equation*}
    • \begin{equation*} \ln|K| + C \end{equation*}
    🔗
    🔗

    Subsubsection ✔ Clickable-Area Questions

    Let students pick out the correct formula, diagram, or expression by clicking on it directly.
    🔗
    Checkpoint 4. Integration by Parts.
    Click on the correct integration by parts formula.
    🔗
    \(\vphantom{m}\)
    \(\displaystyle \int u\ dv = u\ v + \int v\ du\)
    \(\displaystyle \int u\ dv = u\ v - \int u\ dv\)
    \(\vphantom{m}\)
    \(\displaystyle \int u\ dv = u\ v - \int v\ du\)
    \(\displaystyle \int u\ dv = u\ dv - \int v\ du\)
    \(\vphantom{m}\)

    Subsubsection DoenetML

    DoenetML is a newer platform designed specifically for interactive math documents. The example below lets students drag vectors to visualize a determinant identity, which is the kind of thing that is genuinely hard to show on paper.

    Subsubsection JSXGraph

    JSXGraph is a lightweight JavaScript library for interactive geometry and function plots. PreTeXt lets you author JSXGraph code in a separate file and pull it in with a short tag.
