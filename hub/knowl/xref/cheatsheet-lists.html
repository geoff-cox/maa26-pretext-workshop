Lists.

Unordered list
🔗
<ul>
  <li>item</li>
  <li>item</li>
</ul>
The <p> tags inside <li> are optional when the item is a single paragraph.
🔗
Ordered list
🔗
<ol>
  <li>item</li>
  <li>item</li>
  <li>item</li>
</ol>
Add cols="2" or cols="3" on the <ol> to lay items out in columns.
🔗
Description list
🔗
<dl>
  <li>
    <title>Term</title>
    <p>Description.</p>
  </li>
  <li>
    <title>Term</title>
    <p>Description.</p>
  </li>
</dl>
Optional attribute: width="narrow" keeps the term column compact.
