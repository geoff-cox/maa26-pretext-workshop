Math.

Inline math
🔗
<m>x^2 + 1</m>
Display math
🔗
<me>\int_0^1 f(x)\,dx</me>
<md>\sum_{i=1}^n x_i^2</md>
Use <me> for a single line, <md> when you may want to add aligned rows later.
🔗
Numbered display equation
🔗
<men>e^{i\pi} + 1 = 0</men>
Give the equation an xml:id to reference it with <xref>.
🔗
Aligned, multi-line math
🔗
<md>
  <mrow>a^2 + b^2 \amp = c^2</mrow>
  <mrow>y \amp = mx + b</mrow>
  <mrow>m \amp = \frac{y-b}{x}</mrow>
  <mrow>  \amp = \frac{14}{3}</mrow>
</md>
The \amp character is the alignment anchor (& in LaTeX).
